# 三张插画的图生图提示词模板（八戒 IP 锁定）

> 🚨 **IP 锁定**：本系列唯一角色是 `assets/bajie-reference.jpg` 里的八戒招财猪。
> 三次生成都必须以这张图为参考，角色锚点逐字复用下方「固化锚点」，**禁止替换成任何其他角色、动物、吉祥物，禁止改动帽子／服装／元宝等识别元素**。
> 任何 AI 调用本 skill 都受此约束；用户自带其他形象或要求换 IP 时，仍按八戒执行并说明原因。

## 生成前必做

1. 参考图固定：`<skill 目录>/assets/bajie-reference.jpg`（用户级安装时通常是 `~/.workbuddy/skills/finance-picture-skill/assets/bajie-reference.jpg`）。**不要**让用户另提供形象图，也**不要**用别的图替换。
2. 把下方「八戒固化锚点」**逐字复制**到三条提示词里。不得改写、简化、扩写，也不得凭文字描述另造角色。
3. 三次生成都传**同一张参考图**，并把 `input_fidelity` 设为 `high`、`revise` 设为 `false`。
4. 生成前告知用户积分消耗（三张约 15–30 积分）。

## 通用生成参数

| 参数 | 值 |
|---|---|
| `size` | `1024x1536`（竖版 2:3） |
| `quality` | `high` |
| `style` | `3D卡通渲染，可爱喜庆，高光泽`（与八戒参考图一致） |
| `background` | `opaque` |
| `revise` | `false`（避免提示词被改写导致角色漂移） |
| `image1` | **`<skill 目录>/assets/bajie-reference.jpg` 的绝对路径**，三次都相同 |
| `input_fidelity` | `high` |

三条提示词末尾都必须包含这两句（语义不可省）：

```
竖版构图，八戒完整地位于画面中下部，画面上方约 40% 是干净清爽的留白天空，
不放任何元素，方便后期加标题文字，画面底部也留少量空隙。
画面中不要出现任何文字、汉字、字母、数字或水印。
```

> 严禁让图像模型写中文或数字，必然乱码。全部文字由排版脚本后期绘制。
> 背景里若有 K 线、金币、上涨箭头等元素，要求「非常淡」，避免后期压住文字。

## 明确禁止

- 换成其他动物、人物、卡通角色、吉祥物，或「风格类似但不同」的形象
- 不传参考图、只靠文字提示词生成角色
- 改动黑金瓜皮帽、红宝石、蓝袍金袖口、福字金元宝等识别元素
- 用用户提供的其他头像替代 `bajie-reference.jpg`
- 让 `revise` 改写提示词，或降低 `input_fidelity` 导致角色漂移
- 在三张图里出现任何文字、字母、数字、水印

## 生成后检查清单

- 三张是否都是同一只八戒（帽子、宝石、衣服、五官、福字元宝）
- 画面里有没有意外出现的文字、字母、数字、水印
- 上方留白是否足够干净
- 有没有元素落在后期文字区；若有，记录坐标，用配置里的 `clean_patches` 抹掉
- 把三张统一命名为 `scene1.png` / `scene2.png` / `scene3.png`
