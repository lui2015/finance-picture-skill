# 三张插画的图生图提示词模板

## 生成前必做

1. 先查看用户提供的角色参考图，写出一段**角色锚点**：物种/主体、主色、五官细节、帽子、服装、手持道具、画风、光线、背景元素。
2. 这段锚点必须**逐字复制**到三条提示词里，这是三张角色一致的关键。
3. 三次生成都传**同一张参考图**，并把 `input_fidelity` 设为 `high`。
4. 生成前告知用户积分消耗（三张约 15–30 积分）。

## 通用生成参数

| 参数 | 值 |
|---|---|
| `size` | `1024x1536`（竖版 2:3） |
| `quality` | `high` |
| `style` | 与参考图一致的画风描述，如「3D卡通渲染，可爱喜庆，高光泽」 |
| `background` | `opaque` |
| `revise` | `false`（避免提示词被改写导致角色漂移） |
| `image1` | 用户参考图的本地绝对路径 |
| `input_fidelity` | `high` |

三条提示词末尾都必须包含这两句（可按需译成中文，语义不可省）：

```
竖版构图，角色完整地位于画面中下部，画面上方约 40% 是干净清爽的留白天空，
不放任何元素，方便后期加标题文字，画面底部也留少量空隙。
画面中不要出现任何文字、汉字、字母、数字或水印。
```

> 严禁让图像模型写中文或数字，必然乱码。全部文字由排版脚本后期绘制。
> 背景里若有 K 线、金币、上涨箭头等元素，要求「非常淡」，避免后期压住文字。

## 生成后检查清单

- 三张角色是否像同一只（帽子、衣服、五官、道具）
- 画面里有没有意外出现的文字、字母、数字、水印
- 上方留白是否足够干净
- 有没有元素落在后期文字区；若有，记录坐标，用配置里的 `clean_patches` 抹掉
- 把三张统一命名为 `scene1.png` / `scene2.png` / `scene3.png`
