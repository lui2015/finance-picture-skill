# 三张插画的图生图提示词模板（八戒 IP）

> 🚨 **锁身份，不锁姿势**：唯一角色是 `assets/bajie-reference.jpg` 里的八戒招财猪，帽子、红宝石、蓝袍、福字金元宝、3D 画风等**身份元素**三次都不变。
> 但**表情、视线、手势、身体姿态要随每张知识点语义变化**，三张之间必须明显不同。禁止三张都生成「双手捧元宝微笑看镜头」。
> 任何 AI 调用本 skill 都受此约束；用户自带其他形象或要求换 IP 时，仍按八戒执行并说明原因。

## 一、一致性边界

## 三、生成前必做

1. 参考图固定：`<skill 目录>/assets/bajie-reference.jpg`（用户级安装时通常是 `~/.workbuddy/skills/finance-picture-skill/assets/bajie-reference.jpg`）。**不要**让用户另提供形象图，也**不要**用别的图替换。
2. 把下方「八戒身份锚点」**逐字复制**到三条提示词里。不得改写、简化、扩写，也不得凭文字描述另造角色。
3. 按该期概念的三张语义，各写一段具体的 `{{本张表情与动作}}`（表情 + 视线 + 手势/姿态 + 可选辅助道具），三张互不相同。
4. 三次生成都传**同一张参考图**，`input_fidelity=high`、`revise=false`。
5. 生成前告知用户积分消耗（三张约 15–30 积分）。

## 六、通用提示词骨架

三条提示词都用这个骨架，只替换 `{{八戒身份锚点}}`、`{{背景描述}}` 和**逐张不同的** `{{本张表情与动作}}`：

```
以参考图中的八戒为主角，严格保持身份锚点完全一致：{{八戒身份锚点}}。
【本张表现】{{本张表情与动作}}。
只改变表情、视线、头部姿态、手势与身体姿态；帽子、红宝石、蓝袍金袖口、福字金元宝与 3D 画风保持原样。
{{背景描述}}，画面干净通透。
竖版构图，八戒完整地位于画面中下部，画面上方约 40% 是干净清爽的留白天空，
不放任何元素，方便后期加标题文字，画面底部也留少量空隙。
画面中不要出现任何文字、汉字、字母、数字或水印。
```

> 严禁让图像模型写中文或数字，必然乱码。全部文字由排版脚本后期绘制。
> 背景里的 K 线、金币、上涨箭头要求「非常淡」，避免后期压住文字。

## 七、ROE 示例（仅示例，不是固定模板）

以下三行是 ROE 这一期的 `{{本张表情与动作}}` 填法。换概念时按第二节语义表重新设计：

- **第 1 张「是什么」**：八戒头微微歪向一侧，眼睛发亮、眉毛上扬，露出好奇的表情，视线看向画面外的问号气泡；双手把福字金元宝捧在胸前稍微凑近，头顶飘着几个柔和的金色问号气泡和小星星。
- **第 2 张「怎么算」**：八戒微微低头、眼睛微眯、神情认真专注；一只手把福字金元宝抱在怀侧，另一只手拿着金色小算盘正在拨珠子，身前摆着一小堆闪亮金币和一个金色天平。
- **第 3 张「避坑」**：八戒眉毛微皱、表情带一点提醒意味，侧身站在一摞金币台阶上；一手把福字金元宝高高单手举起，另一手向前摆手示意「别急」，旁边有柔和的金色上升曲线箭头和一枚小金色盾牌。

注意三张分别是「歪头捧宝好奇」「低头打算盘专注」「侧身举宝摆手提醒」——表情、视线、手势、身体姿态都不同。

## 八、明确禁止

- 换成其他动物、人物、卡通角色、吉祥物，或「风格类似但不同」的形象
- 不传参考图、只靠文字提示词生成角色
- 移除或替换黑金瓜皮帽、红宝石、蓝袍金袖口、福字金元宝等身份元素；把元宝换成别的道具
- **三张使用同一个表情、同一个手势、同一个姿势**（尤其是三张都「双手捧元宝微笑看镜头」）
- **把表情或姿势写进身份锚点**，导致后面无法变化
- 用用户提供的其他头像替代 `bajie-reference.jpg`
- 让 `revise` 改写提示词，或降低 `input_fidelity` 导致角色漂移
- 在三张图里出现任何文字、字母、数字、水印

## 九、生成后检查清单

- 三张是否都是**同一只八戒**（帽子、宝石、衣服、五官、福字元宝、画风）
- 三张的**表情 / 视线 / 手势 / 身体姿态是否明显不同**，且各自呼应本张知识点
- 画面里有没有意外出现的文字、字母、数字、水印
- 上方留白是否足够干净
- 有没有元素落在后期文字区；若有，记录坐标，用配置里的 `clean_patches` 抹掉
- 因姿势不同，`portraits` 需逐张重新量裁剪框，不要复用同一组坐标
- 把三张统一命名为 `scene1.png` / `scene2.png` / `scene3.png`
